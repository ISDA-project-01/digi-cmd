# DigiShell Architecture Documentation

DigiShell is an AI command shell for Windows, Linux, and macOS.
Features local Ollama qwen2.5:3b integration, reinforcement path resolving, and 10 command instructors:
- `$` : non AI command
- `@` : mention location, directory, area
- `!` : teaches to use that command / alias
- `?` : for help and explanation
- `:` : to show all possible commands for the request
- `;` : shows full processes done with workflow
- `*` : AI emulsification or justification for the output
- `-` : meanings with detailed syntax
- `#` : to fix the error if occurs
- `^` : to install anything needed and update needed
